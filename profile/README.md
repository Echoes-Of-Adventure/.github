| Echoes of Adventure: Factions | Adds player-controlled factions that can interact with other factions, form alliances or conflicts, and even join NPC factions. | Planned | Private |
| Echoes of Adventure: Currency | Introduces a currency system with coins, trading mechanics between players, and integration with vanilla NPCs. | Dev | Private |
| Echoes of Adventure: Radial Menu | Adds a customizable radial menu where players can dynamically assign hotkeys or commands for quick access, reducing the need for multiple keybinds. | Dev | Private |
| Echoes of Adventure: Teams | Implements a team system allowing players to create and manage their own teams. Includes a visual teammate list with health, player head icon, nickname, and more. Integrated with Mine and Slash. | Planned | Only MES Server |
| Echoes of Adventure: Utilities | Various utility features that fix certain mechanics, introduce restrictions, and provide full datapack configuration support. | Beta | Only MES Server |
| Echoes of Adventure: Ranks | Custom player rank (title) system where players can earn titles through achievements or receive them from administrators. Titles can be selected and displayed as chat prefixes. | Dev | Only MES Server |
| Echoes of Adventure: Chronicles | Enhanced visual information hub featuring news, guides, and multi-channel chat support. | Dev | Only MES Server |
| Echoes of Adventure: Cities | Smart NPCs and settlement evolution system allowing villages to grow and develop from small settlements into full cities.| Planned | Only MES Server |
| Echoes of Adventure: Healthfire | Overhauled food system with changes to farming, cooking, and food mechanics. | Planned | Only MES Server | 
| Echoes of Adventure: Pharma | Adds a disease system where players can contract illnesses and receive debuffs, requiring careful health management. | Planned | Only MES Server |
| Echoes of Adventure: Brewing | Introduces alcohol brewing with a more complex cooking and crafting process. | Planned | Only MES Server |
| Echoes of Adventure: Forging | Complete overhaul of forging and metal crafting mechanics. | Planned | Only MES Server |
| Echoes of Adventure: Structures | Adds new structures and reworks existing ones. | Dev | Only MES Server |
| Echoes of Adventure: Dimensions | Introduces a custom portal system and 18 new dimensions… Don’t ask. | Planned | Only MES Server |
| Echoes of Adventure: Quests | Custom quest system integrated with Cities, Factions, Ranks, and Compass systems. | Planned | Only MES Server |
| Echoes of Adventure: Mobs | Full control over mob spawning mechanics, with the possibility of adding new mobs. | Planned | Only MES Server |
